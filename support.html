Frequently Asked Questions

How do I connect my 3D printer?

Go to Settings, enter your printer's local IP address and OctoPrint API key. Your printer must be on the same Wi-Fi network as your device.

Which file formats are supported?

LayerLab supports .gcode, .gco, and .g file formats.

How does cost estimation work?

Cost is calculated based on filament usage (weight and spool price), electricity consumption (printer wattage and energy price), and optional labor/depreciation rate. Configure these in Settings.

What is LayerLab Pro?

Pro unlocks advanced features like PDF proposal generation and removes ads. You can subscribe from the app.

How do I restore my purchase?

Open the app, go to the Pro upgrade screen, and tap "Restore Purchases". Make sure you're signed in with the same Apple ID you used for the original purchase.

Does the app work offline?

Yes. G-code visualization, analysis, and cost estimation all work offline. An internet connection is only needed for ads and printer remote control features.
